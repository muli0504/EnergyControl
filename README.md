# Energy-Adaptive Synchronization in FitzHugh–Nagumo Networks

Code for the simulations and analyses presented in:

**Optimization of energy-efficient synchronization in neuronal networks under limited coupling resources**

This repository provides MATLAB codes for studying energy-difference-based adaptive coupling and synchronization dynamics in FitzHugh–Nagumo (FHN) neuronal networks.


## Overview

This repository contains the MATLAB scripts used for the numerical simulations in the study. The code includes:

- **`Main/`**: Main simulation programs for generating synchronization results.

- **`NetworkAnalyse/`**: Functions for constructing networks, solving FHN dynamics, calculating coupling interactions, and evaluating synchronization-related quantities.

- **`Robustness/`**: Scripts for robustness analysis, including sensitivity analyses of simulation time, coupling parameters, energy thresholds, and network structures.


## Requirements

- MATLAB
- Parallel Computing Toolbox
